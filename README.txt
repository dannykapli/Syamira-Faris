# Syamira & Faris — Wedding Invitation Website

A romantic, responsive wedding invitation website using the supplied wedding photos.

## Files
- `index.html` — main page
- `style.css` — design and responsive layout
- `script.js` — opening screen, countdown, calendar download and photo lightbox
- `assets/` — 9 supplied wedding photos

## How to use
1. Keep the folder structure unchanged.
2. Open `index.html` in a browser to preview it.
3. To publish publicly, upload the whole folder to a static hosting service.

## Included features
- Animated "Open Invitation" cover
- Countdown to 19 September 2026, 11:00 AM (Malaysia time)
- Wedding venue and Google Maps button
- English wedding programme
- Add-to-calendar `.ics` download
- WhatsApp contact buttons
- Responsive mobile/desktop layout
- Photo gallery with fullscreen lightbox
- Romantic dusty-pink / ivory / gold theme

## Easy edits
Open `index.html` in VS Code and search for the text you want to change.
